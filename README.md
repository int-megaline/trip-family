# 후쿠오카 · 유후인 · 벳푸 가족여행 대시보드

2026.11.06(금) ~ 11.09(월), 3박4일 규슈 가족여행을 위한 단일 정적 사이트입니다.
일정 요약, 일자별 상세 타임라인, 예산·비용 트래커, 여행 정보를 모바일/태블릿/PC에서
반응형으로 확인할 수 있습니다.

## 구성

js/common.js  다크모드 토글 · 햄버거 메뉴 · 툴팁 · 포맷 유틸리티 · 서비스 워커 등록

## 주요 기능

- **반응형 카드형 레이아웃**: 모바일/태블릿/PC 모든 화면에서 표가 카드 형태로 전환됩니다.
- **라이트/다크 모드**: 헤더의 토글 버튼으로 전환하며 선택값은 브라우저에 저장되어 다음 방문 시에도 유지됩니다.
- **예산·비용 트래커**: 날짜·항목(드롭다운)·상세·엔화 비용을 입력하면 해당 날짜의 환율
  ([Frankfurter Exchange Rates API](https://frankfurter.dev/), ECB 기준)을 자동 조회해 원화로 환산하고,
  일별/전체 누적 합계와 카테고리별 계획 대비 실사용 비교 차트를 즉시 갱신합니다.
  입력 데이터는 **브라우저(기기)의 localStorage에 저장**되며, 다른 기기·가족과 공유하려면
  트래커 페이지의 "내보내기/가져오기" 버튼으로 JSON 파일을 주고받으면 됩니다.
- **툴팁**: 세부 메모가 있는 일정은 `?` 아이콘을 탭/클릭하면 추가 설명이 표시됩니다.
- **출처 각주**: 각 페이지 하단에 실제 데이터 출처(구글시트 원본, 관광청 공식 사이트, 위키미디어 등)를
  번호와 링크로 정리했습니다.

## 데이터 출처 및 참고 사항

- 일정·사전결제 금액 원본: Google Sheets 「일본 - 정선 가족 여행」 `schedule-final` 시트
- 항공권 사전결제 금액(₩24,410,000)은 원본 시트에 1인 단가(48.82만원) 대비 매우 높게
  기재되어 있어 대시보드에도 경고 문구로 표시해 두었습니다. 실제 결제 내역과 대조 확인을 권장합니다.
- 명소 사진은 Wikimedia Commons의 자유 이용 이미지를 사용했으며, 각 사진 하단에 출처 링크가 있습니다.
- 환율은 참고용 자동 조회이며, 실제 카드/현금 결제 환율과 다를 수 있습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `fukuoka-family-trip`).
2. 이 폴더의 파일을 저장소에 푸시합니다.

   ```bash
   git remote add origin https://github.com/<사용자명>/<저장소명>.git
   git branch -M main
   git push -u origin main
   ```

3. 저장소 **Settings → Pages**에서 **Source**를 `Deploy from a branch`,
   **Branch**를 `main` / `/ (root)`로 설정하고 저장합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 사이트가 공개됩니다.

> 별도 빌드 과정이 없는 순수 정적 사이트이므로 위 설정만으로 바로 배포됩니다.

## 앱(PWA)으로 설치하기

GitHub Pages로 배포하면(HTTPS 필수, Pages는 기본 HTTPS) 브라우저에서 **홈 화면 앱**처럼
설치해 아이콘을 탭 한 번으로 바로 열 수 있고, 이전에 열어본 페이지는 인터넷이 없어도
캐시에서 열립니다(입력 데이터는 항상 그대로 유지됨).

- **iPhone (Safari)**: 사이트 접속 → 하단 공유 버튼(⬆️) → **홈 화면에 추가**
- **안드로이드 (Chrome)**: 사이트 접속 → 우측 상단 점 3개 메뉴 → **앱 설치** (또는 주소창의 설치 아이콘)
- **PC (Chrome/Edge)**: 사이트 접속 → 주소창 오른쪽의 설치 아이콘(⊕ 또는 화면 모양) 클릭 → **설치**

설치 후에는 별도 앱처럼 자체 아이콘으로 실행되며 브라우저 주소창이 보이지 않습니다.
`manifest.json`(앱 이름/아이콘/테마색)과 `sw.js`(오프라인 캐싱, 앱 파일이 추가/변경될 때마다
`CACHE_VERSION` 값을 올려주면 다음 방문 시 자동 갱신됨)가 이 기능을 담당합니다.
